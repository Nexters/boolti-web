# 모바일 검색어 입력 후 대관료 단계 전환 설계

## 목표

공연장 검색 페이지의 모바일 장소 입력 화면에서 사용자가 자동완성 항목을 선택하지 않고 검색어를 직접 입력한 뒤 Enter를 누르면, 검색을 즉시 적용하거나 바텀시트를 닫지 않고 대관료 선택 단계로 이동한다.

## 범위

- 모바일 장소 입력의 Enter 처리만 변경한다.
- 입력한 검색어는 로컬 초안으로 유지한다.
- Enter 시점에는 URL 검색 조건, 공연장 검색 API 요청, 최근 검색어를 갱신하지 않는다.
- 대관료 단계의 하단 `검색하기` 버튼을 누를 때 기존 `applySearch` 흐름으로 검색어와 필터를 함께 적용한다.
- 데스크톱 Enter 검색, 추천 지역 선택, 최근 검색어 선택, 자동완성 지역 선택, 자동완성 공연장 선택 동작은 유지한다.

## 동작 흐름

1. 사용자가 모바일 검색 필터의 장소 상세 화면을 연다.
2. 자동완성 항목을 선택하지 않고 검색어를 입력한다.
3. 모바일 키보드의 검색/Enter를 누른다.
4. 기본 form 제출을 막고 모바일 입력의 포커스를 해제한다.
5. 입력 초안을 유지한 채 활성 검색 필드를 `rentalFee`로 전환한다.
6. 사용자가 대관료 등 나머지 필터를 선택하고 하단 `검색하기`를 누르면 기존 검색 적용 경로가 실행된다.

## 구현 경계

공용 키보드 처리기에서 `isMobile && activeSearchField === 'keyword'`인 경우만 단계 전환을 수행한다. 그 외 Enter 이벤트는 기존 `submitSearch(true)` 경로를 유지한다. 별도의 “자동완성 선택 여부” 상태는 추가하지 않는다. 자동완성 선택은 Enter가 아니라 기존 항목 클릭 처리기를 통해 실행되므로 두 경로를 이벤트 경계에서 구분할 수 있다.

## 검증

- 모바일 직접 입력 후 Enter 시 대관료 입력 UI가 나타난다.
- 이 시점에는 URL에 키워드가 반영되지 않고 최근 검색어도 저장되지 않는다.
- 이어서 하단 `검색하기`를 누르면 입력한 키워드가 URL/API 검색 조건에 반영된다.
- 데스크톱에서 Enter를 누르면 기존처럼 즉시 검색된다.
- 모바일에서 자동완성 항목을 선택하면 기존 선택 동작이 유지된다.
